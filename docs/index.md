# anywidget-instruments

The core of the anywidget-instruments family: the base view and Python base
class every widget derives from, the base trait contract and its generator,
the styles and themes, and the kernel liveness. It holds no widget.

| Library | Widgets |
|---|---|
| [anywidget-instruments-industrial](https://anywidgetinstruments.github.io/anywidget-instruments-industrial/) | Gauges, tanks, LEDs, switches, charts, alarms, SCADA objects |
| [anywidget-instruments-automotive](https://anywidgetinstruments.github.io/anywidget-instruments-automotive/) | Speedometer, tachometer, tell-tales, trip computer, cluster |
